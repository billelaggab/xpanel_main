# 🖥️ دليل XPanel

واجهة عربية متجاوبة باتجاه RTL وخط Cairo محليًا. تُعرض القنوات والمشتركون والخوادم في سجل قابل للبحث والفلترة والتصدير، ويمكن تبديل الوضع الفاتح والداكن من الإعدادات.

## 📦 بنية الإصدار

| الملف أو المجلد | الوظيفة |
| --- | --- |
| `web/` | مكوّنات React وتصميم الواجهة المشترك بين المعاينة وحزمة PHP. |
| `compat/` | مصادر تسجيل الدخول وواجهة التخزين وإعدادات تقديم اللوحة عبر Nginx. |
| `build.mjs` | يجمع CSS وJavaScript وأجزاء خط Cairo ويولّد الحزمة والملف المرافق. |
| `release/` | شجرة النشر الجاهزة، وتشمل `admin/` و`nginx/conf/`. |
| `xpanel.zip` و`xpanel.zip.sha256` | الحزمة الموضوعة ضمن Assets وبصمتها. |

من جذر المشروع:

```bash
npm ci
node xpanel/build.mjs
python3 install.py --check-xpanel
```

يمكن ضغط `release/` أو `xpanel/` يدويًا بعد البناء: يقبل المثبّت ملفات النشر في جذر ZIP، أو تحت `xpanel/` أو `release/` أو `xpanel/release/`. لا يُنسخ سوى الأعضاء المعتمدين؛ ليس مطلوبًا رفع ملفات المصدر أو أي أرشيف آخر. إذا أعدت الضغط، احسب البصمة للملف الذي سترفعه بدل استخدام بصمة الحزمة المولّدة.

## 🔐 تهيئة نسخة محلية

يتحقق `install.py` من هيكل الأرشيف وبصمته إذا توفرت محليًا، ويشترط البصمة عند التنزيل من GitHub Releases. راجع [دليل النشر](../README.md) لخيارات المصدر. لنشر اللوحة على مسار جديد:

```bash
python3 install.py --xpanel-only --target "$HOME/xpanel-site" --state-dir "$HOME/xpanel-data"
XPANEL_STATE_DIR="$HOME/xpanel-data" php -S 127.0.0.1:8090 -t "$HOME/xpanel-site/admin"
```

افتح `http://127.0.0.1:8090/`. استخدم إصدارًا مدعومًا من PHP. الخادم المدمج للاختبار المحلي فقط. للنشر عبر PHP-FPM، يشير `fastcgi_pass php` إلى upstream يُعرّفه مدير الخادم لمقبس PHP-FPM المحلي. ضمّن `xpanel_http.conf` في كتلة `http`، واضبط مجموعة عامل PHP عبر `--web-group` إذا اختلفت عن حساب تجهيز الملفات. الوصول محصور بالمضيف المحلي افتراضيًا؛ هذا الأمر لا يعيد تحميل خدماتك.

> [!CAUTION]
> لا يستبدل وضع `--xpanel-only` مجلد `admin/` قائمًا إلا مع `--replace-admin`. احتفظ بنسخة احتياطية قبل الاستبدال. استخدم `--rotate-password` فقط إذا أردت تغيير بيانات الدخول؛ يبقى سجل اللوحة في مجلد البيانات المنفصل.

## 🧪 المعاينة والتوافق

- `/xpanel` معاينة تجريبية تعتمد على PostgreSQL عبر Drizzle. تُفصل التعديلات بين المتصفحات، ولا ينبغي استخدام بيانات عملاء حقيقية فيها.
- `/report` يحتفظ بالتحليلات التاريخية. نسخة PHP تبدأ بسجل خاص بها؛ لا تستورد MySQL ولا تعدّل محرك البث.
- `MAIN` يستهلك `xpanel.zip` فقط لتثبيت اللوحة. `LB` لا يثبّت لوحة. لم يُجرَ تثبيت شامل لمكوّنات الخادم القديمة.
